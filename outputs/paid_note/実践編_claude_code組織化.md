## 第1章：この実践編で手に入るもの（概要）

前編では「動線」と「4部隊」という構造の話をした。
この実践編で渡すのは、構造ではなく実物そのものである。

具体的には次の3つを渡す。

- そのままコピーして使える `CLAUDE.md` の完成形テンプレート
- 4部隊（buzz_post / engagement / free_note / paid_note）の定義ファイル
- 初日に何をどの順番で渡すか、という実際の動かし方

読み終えた時点で、ファイルを置く場所と、最初に打つコマンドが分かっている状態になる。
「分かった」で終わらせず、「今日中に1部隊だけ動かしてみる」ところまでが、この実践編の範囲である。

*(本セクションは概要版。完成稿では1,800〜2,000字を想定)*

## 第6章：1週間運用したときに起きる典型的なズレと直し方（概要）

それぞれに対する `CLAUDE.md` / 各部隊ファイルの修正例を提示する。
